# Advancing Student Writing Through Automated Syntax Feedback

[![Paper](https://img.shields.io/badge/AIEER_2024-paper-b31b1b)](https://arxiv.org/abs/2501.07740)
[![Dataset](https://img.shields.io/badge/%F0%9F%A4%97_Dataset-Essay--Syntax--Instruct-yellow)](https://huggingface.co/datasets/Kamyar-zeinalipour/Essay-Syntax-Instruct)
[![Models](https://img.shields.io/badge/%F0%9F%A4%97_Collection-3_models-orange)](https://huggingface.co/collections/Kamyar-zeinalipour/automated-syntax-feedback-aieer-2024-6af487599293af6e63c227f9)
[![License](https://img.shields.io/badge/code-Apache_2.0-blue)](LICENSE)

Give students detailed feedback on the **syntax** of their English essays. The models read an essay
and return structured feedback across eight categories — spelling, conjunctions and connectives,
modifiers, prepositions, modal verbs, punctuation, articles and pronouns — with examples from the
essay and suggestions for each.

This repository accompanies [*Advancing Student Writing Through Automated Syntax Feedback*](https://arxiv.org/abs/2501.07740)
(AIEER 2024). Everything is gathered in the
[Automated Syntax Feedback collection](https://huggingface.co/collections/Kamyar-zeinalipour/automated-syntax-feedback-aieer-2024-6af487599293af6e63c227f9).

## Data

[**Essay-Syntax-Instruct**](https://huggingface.co/datasets/Kamyar-zeinalipour/Essay-Syntax-Instruct): 8,049
training and 600 test essays, each with syntax feedback generated by GPT-3.5-Turbo using the prompt
in [`data_generation/prompts.py`](data_generation/prompts.py).

```python
from datasets import load_dataset
ds = load_dataset("Kamyar-zeinalipour/Essay-Syntax-Instruct")   # essay, feedback
```

To build feedback for your own essays:

```bash
pip install openai pandas tqdm
export OPENAI_API_KEY=...
python data_generation/generate_feedback.py essays.csv feedback.csv
```

## Models

| Base model | Adapter | ROUGE-L (base → fine-tuned) |
|---|---|---|
| [Llama-2-7b-chat](https://huggingface.co/meta-llama/Llama-2-7b-chat-hf) | [Llama2-7B-Syntax-Instruct](https://huggingface.co/Kamyar-zeinalipour/Llama2-7B-Syntax-Instruct) | 0.185 → **0.343** |
| [Llama-2-13b-chat](https://huggingface.co/meta-llama/Llama-2-13b-chat-hf) | [Llama2-13B-Syntax-Instruct](https://huggingface.co/Kamyar-zeinalipour/Llama2-13B-Syntax-Instruct) | 0.214 → **0.347** |
| [Mistral-7B-Instruct-v0.2](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.2) | [Mistral7B-Syntax-Instruct](https://huggingface.co/Kamyar-zeinalipour/Mistral7B-Syntax-Instruct) | 0.205 → **0.369** |

```python
import torch
from peft import PeftModel
from transformers import AutoModelForCausalLM, AutoTokenizer

base = "mistralai/Mistral-7B-Instruct-v0.2"
tokenizer = AutoTokenizer.from_pretrained(base)
model = AutoModelForCausalLM.from_pretrained(base, torch_dtype=torch.bfloat16, device_map="auto")
model = PeftModel.from_pretrained(model, "Kamyar-zeinalipour/Mistral7B-Syntax-Instruct").merge_and_unload()
```

## Training

```bash
pip install -r requirements.txt
scripts/train_mistral.sh      # also train_llama7b.sh, train_llama13b.sh
```

LoRA r = 32, α = 64, dropout 0.1 on all attention and MLP projections plus the embeddings and LM
head; 3 epochs; AdamW, learning rate 1e-4 with cosine decay, weight decay 1e-4; 8 sequences per
GPU × 4 accumulation steps; up to 2,048 tokens; bf16, DeepSpeed, Flash Attention 2, seed 100.
